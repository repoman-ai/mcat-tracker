Account key calculator

Run this once when you create your Supabase account. It turns the PIN you want to use into the long account password Supabase should store, so the value in the auth table is never a short number that could be guessed.

Nothing here is sent anywhere

The calculation happens entirely in this browser tab. Your PIN is never transmitted, never logged, and never saved. Close the tab and it is gone.

Use at least four digits. You will type this PIN to unlock a new device. If you forget it, the tracker can send a secure reset link to your owner email.

Account password for Supabase

Copy this whole value into the Password field when you create the user in Supabase → Authentication → Users → Add user. Then never type it again — you will only ever type your PIN.

The rest of the one-time setup

  1. Create a Supabase project.
  2. Run supabase/schema.sql in its SQL Editor.
  3. Turn off public sign-ups, and turn off "Confirm email", under Authentication → Sign In / Providers → Email.
  4. Add one user with your email and the calculated password above.
  5. Paste the project URL and publishable key into js/sync-config.js.
  6. Open the tracker, enter your email and PIN, and you are unlocked.
