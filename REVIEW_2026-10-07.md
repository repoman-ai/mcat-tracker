# Motivational-message review — October 7, 2026

Reviewed `16da1252e6d3c5a6145d5e87f2fa9402fae6fd2a` (“Add prominent study messages with daily phrase and kicker rotation”). The remote `main` branch was checked and points to this commit. Fixes are in the working tree; they have not been committed or pushed.

## Findings and fixes

1. **P2 — An idle foreground page could show yesterday's message indefinitely.** Rotation depended on a render or a visibility change. Added a minute-by-minute local-date check that refreshes the tracker after midnight, including message selection and expired dismissal. Background returns still check immediately. Date previews remain fixed to their specified date.
2. **P2 — Malformed cosmetic storage could prevent Today from rendering.** Numeric/object `current.text` reached a string-only `includes()` call during replacement. Selection now handles these values safely. Cached text and ending combinations must also match the eligible phrase pool; invalid or future selection timestamps trigger recovery.
3. **P2 — Editing notes on past work could falsely count as studying today.** The feature used the generic `updatedAt` timestamp. Added `lastStudiedAt` to daily records and updated checklist, completion, status and day-detail writes. Notes, reopens, deferral/resume and undo preserve the prior study time. Increased question/CARS counts and new checked steps record study time. Record-level sync and backups preserve the added field.
4. **P2 — Catch-up work could select encouragement without sustaining a streak.** Streak calculation now also checks study activity recorded on each scheduled study date, including work on older assignments. Protected rest days still neither create nor break a streak.

Phrase and kicker wording, IDs, pools, optional-kicker rules and countdown boundaries are unchanged. A byte-for-byte comparison verified the complete copy/pool block against the reviewed commit. Module cache URLs were updated through the import graph so deployed browsers fetch the corrected code.

## Limits

Older daily records do not distinguish study edits from note edits. Their original timestamp remains the compatibility fallback until a new edit preserves or updates the dedicated study field. This avoids rewriting historical progress based on guesses.

Messages remain quiet on rest days, unconfirmed test-window dates, dates outside the plan, Completed and other views. A continuously visible Today page rotates daily; additional four-hour rotation occurs on returns to Today rather than interrupting an ongoing session. Different devices continue to keep independent cosmetic histories.

No further reproducible failures were found in the reviewed changes or the full regression suite. The tests are not an exhaustive audit of every unrelated application feature. This work does not require a new chat.
